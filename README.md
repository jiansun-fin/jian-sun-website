# jian-sun.com

Personal academic website of Jian Sun — Associate Professor of Finance, Singapore Management University.

Single-file static site (`index.html`), hosted on GitHub Pages.

## Local preview
Open `index.html` in a browser, or use the VS Code **Live Server** extension for auto-refresh.

## Publish
Push to `main`; GitHub Pages redeploys automatically.

## Editing
See `CLAUDE.md` for design tokens and conventions.
